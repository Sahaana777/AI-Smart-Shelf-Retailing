# AI-Powered Smart Retail Shelf Monitoring and Competitor Analysis

An AI-based retail shelf monitoring system using **YOLO object detection** and computer vision to detect supermarket products from shelf images, count visible products, estimate shelf availability, and support competitor shelf analysis.

## Project Overview

Manual shelf audits are time-consuming and depend heavily on store staff. Products that are low in stock, unavailable, misplaced, or belonging to competitors can be missed during routine checks.

This project proposes a camera-based computer vision system that analyzes shelf images or video using a fine-tuned YOLO model.

The current implementation focuses on the core product detection and counting pipeline.

```text
Shelf Image / Video
        ↓
Image Preprocessing
        ↓
Fine-tuned YOLO
        ↓
Product Detection
        ↓
Confidence Filtering
        ↓
Product Counting
        ↓
Shelf Analytics
        ↓
Dashboard / Alerts
```

## Objectives

- Detect and classify selected supermarket products from shelf images or video.
- Count visible product instances by product or brand.
- Estimate shelf occupancy and identify shelf gaps.
- Compare target-brand shelf presence with competitors.
- Provide data for store-level monitoring and decision support.

## Current Implementation

The current prototype implements the initial computer vision pipeline:

- Product dataset preparation
- Product image annotation
- YOLO dataset creation
- YOLO model fine-tuning
- Product detection from shelf images
- Confidence-based detection filtering
- Product counting

### Current Output

Given a shelf image, the system produces:

1. Bounding boxes around detected products.
2. Product/class labels.
3. Detection confidence scores.
4. Product-level counts.

Example:

```text
Product Count
----------------
Oreo       : 8
GoodDay    : 5
Bourbon    : 3
HideSeek   : 2
```

## Dataset

The dataset consists of shelf/product images containing the selected supermarket products.

Each product instance is annotated using bounding boxes and assigned to a corresponding product class.

The dataset is divided into:

- Training set
- Validation set
- Test set

The specific product classes and dataset size will be updated as the dataset is finalized.

## Model Training

A pretrained YOLO model is fine-tuned using the custom retail shelf dataset.

Training involves:

1. Preparing annotated images.
2. Splitting the dataset into training, validation, and test sets.
3. Training the YOLO model.
4. Evaluating model performance.
5. Selecting the best-performing model for inference.

### Evaluation Metrics

The model will be evaluated using:

- Precision
- Recall
- mAP

These metrics will be updated with the actual results obtained during training.

## Installation

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd AI-Smart-Retail-Shelf-Monitoring
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Activate it on Linux/macOS:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Training

After preparing the YOLO dataset, run:

```bash
python src/train.py
```

The trained model and training results will be generated by the YOLO training process.

## Detection

Place a test shelf image in the appropriate location and run:

```bash
python src/detect.py
```

The output will contain detected products with bounding boxes and confidence scores.

## Product Counting

Run:

```bash
python src/count_products.py
```

The script will count the detected instances of each product class.
